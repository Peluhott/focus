Turn 1 · Undo a delete

Four ways to get a deleted item back

Delete a few to-dos with the trash icon in each frame, then try to recover them. ⌘Z (or Ctrl+Z) undoes the last delete in whichever frame you used last.

1a

Instant delete, Undo toast

No confirm dialogs anywhere. Every delete happens at once and shows a 5-second toast with Undo and a ⌘Z hint. A new delete replaces the toast.

1b

Stacking toast

The toast lasts 10 seconds and pauses while you hover it. Deletes in a row add to the same toast, so one Undo all brings back the whole batch.

1c

Recently deleted

Deletes still get the Undo toast, and the item also moves to a Recently deleted list for 30 days. Restore it from there, or delete it for good.

Find it in search

No separate page. Deleted items show up for 30 days in the search popup under Recently deleted. Pick one to restore it. The toast says where to look.
